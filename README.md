# Universal Document Parser

A versatile Python script to parse and extract text from almost any document format including PDF, DOCX, XLSX, CSV, JSON, HTML, and TXT.

## Setup

1. Clone the repository.
2. Install the required dependencies:

```bash
pip install -r requirements.txt
```

## Usage

Simply run the script and pass the file path as an argument:

```bash
python document_parser.py path/to/file.pdf
```
